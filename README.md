# mekotools/strudel

**Öffentliches Spiegel-Repo des MekoTools-Katalogs.** Enthält keine eigene
Software: Der Inhalt ist das fertige Container-Abbild, das hier veröffentlicht
wird, damit es **ohne Anmeldung** gezogen werden kann.

- Werkzeug: Strudel (Musik per Code beschreiben und im Browser hören, codeberg.org/uzu/strudel)
- Bezug: `docker pull ghcr.io/mekotools/strudel:latest`
- Bauvorschrift: `tilllt/mekotools/mekotools-strudel-0a6d61e1` (interne GitLab-Instanz)
- Lizenz des Werkzeugs: AGPL-3.0
